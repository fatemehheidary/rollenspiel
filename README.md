# rollenspiel

## Projektziel

Wir entwickeln in einer Dreiergruppe ein eigenes Computer-Rollenspiel.
Es baut auf dem Konzept des Arbeitsblatts „Mein erstes Rollenspiel“ auf.
Das Spiel enthält einen eigenen Charakter, Gegner und Kämpfe mit Animationen.

## Technologien

- PHP für die PHP-Klassen und den Spielablauf
- HTML und CSS für die Oberfläche
- JavaScript für die Animationen
- XAMPP und Apache zum lokalen Starten
- GitHub für unseren gemeinsamen Code

## Projekt lokal starten

1. Repository in den XAMPP-Ordner `htdocs` klonen.
2. Apache in XAMPP starten.
3. Im Browser diese Adresse öffnen:

   `http://localhost/rollenspiel/public/`

Falls der Projektordner anders heißt, `rollenspiel` in der Adresse durch den Ordnernamen ersetzen.

## Ordner

- `src/`: PHP-Klassen
- `public/`: sichtbare Spieloberfläche
- `public/api/`: Verbindung zwischen Oberfläche und PHP
- `public/css/`: Gestaltung und Animationen
- `public/js/`: JavaScript
- `public/images/`: Bilder
- `docs/`: Dokumentationen

## Aufgaben

- Person 1: PHP-Klassen für Charaktere und Gegner
- Person 2: Oberfläche und Animationen
- Person 3: Kampfablauf und Verbindung der Programmteile

Die konkreten Aufgaben stehen in den GitHub-Issues.

## Zusammenarbeit mit GitHub

- `main` enthält unseren gemeinsamen, geprüften Stand.
- Für Änderungen erstellen wir einen eigenen Branch.
- Fertige Änderungen werden als Pull Request vorgeschlagen.
- Vor dem Zusammenführen prüft mindestens eine andere Person den Pull Request.
- Die Zusatzfunktionen legen wir gemeinsam fest und dokumentieren sie in den Issues.
